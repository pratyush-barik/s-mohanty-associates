# Git Commit Conventions

When making git commits for this project, always use the following format for commit messages based on the type of change and the bank being worked on:

1. **PDF Renderer Changes:**
   Format: `feat (<bank_name>-pdf): <message>`
   Example for Bank of Baroda (BOB): `feat (BOB-pdf): update layout for structural details`

2. **Web UI (Report Draft) Changes:**
   Format: `feat (<bank_name>-report): <message>`
   Example for Bank of Baroda (BOB): `feat (BOB-report): rename columns in Building Valuation Table`

**Rule:**
Always strictly adhere to this naming convention for any future commits in this project.
